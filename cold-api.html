Cold API

Programmatic access to Cold’s agentic outbound system. Built for platforms, agencies, and teams who want to embed AI-driven prospecting into their own products.

What the Cold API Is

The Cold API gives you direct access to Cold’s outbound intelligence layer. Instead of logging into the Cold UI, you can call Cold programmatically to generate, personalise, and orchestrate outbound activity inside your own workflows.

This is designed for teams building sales platforms, AI products, internal growth systems, or managed outbound services.

What You Can Do With It

  • Generate personalised outbound messages at scale
  • Run agentic prospect research programmatically
  • Trigger messaging from your own systems and events
  • Embed Cold inside CRMs, sales tools, or internal pipelines
  • Control tone, constraints, safety rules, and context via API

Who It’s For

  • B2B SaaS platforms embedding outbound AI
  • Agencies running outbound for multiple clients
  • Growth teams building internal prospecting systems
  • Developers who want infrastructure, not dashboards

How It’s Different From the Cold App

The Cold web app is designed for individual users and small teams. The API is designed for scale, control, and integration.

  • No UI dependency
  • Programmatic control over prompts and logic
  • Multi-tenant and client-aware usage
  • Designed for automation and orchestration

Access & Availability

Cold API access is currently available to approved partners. Pricing, rate limits, and usage models depend on volume and use case.

If you’re building something serious and want to embed Cold properly, this is the correct entry point.
